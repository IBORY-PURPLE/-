## 0. 서비스 개요 — **말길**

> **말길(말+길)은 외국인의 한국어 실력을 '갈 수 있는 한국'으로 환산해 주는 여행 서비스입니다** — 한류 팬이 한국어에 쓰는 시간은 월 **23.8시간**으로 드라마(18.3시간)보다 긴데, 정작 한국관광공사 관광정보 **50,670곳 중 영문으로 열려 있는 곳은 15,640곳(30.9%)뿐**이라, 배운 한국어를 쓰러 갈 길은 아무도 알려주지 않기 때문입니다.
>
> **말길은 장소마다 필요한 한국어 수준을 매겨 실력이 늘수록 지도가 넓어지게 하고 — 한국어는 하루에 늘지 않으므로 방문은 자연히 반복되며 —** 세종학당 89개국 273개소 **23.9만 명**(그중 방한 경로가 있는 사람은 **연 222명, 0.09%**)이라는 **이미 확보된 명단**에서 시작합니다.

### 이름

**말길** = 말 + 길. **"말길이 트이다"** — 말이 통하기 시작한다는 뜻의 한국어 관용구입니다.
심사위원은 설명 없이 알고, 학습자에겐 **이름 자체가 첫 수업**이 됩니다. (표준국어대사전 등재 여부 확인 → §9-17)

## 0-1. ★ 접수 양식 제출본 (확정 2026-07-18)

> **접수 화면 실측**: 필수 필드는 **「서비스명」 + 「서비스 개요」 2개뿐**.
> 성격 = **예비심사(적격/부적격 판단)**용. 배점 심사(1차)는 10월 개발 완료 서비스 대상.
> **결정적 힌트** — 양식 예시 개요가 *"**한국관광공사 국문관광정보 API를 활용한** 국내 여행지 정보 제공 앱 서비스"* 구조.
> → 공사가 직접 "개요 첫머리에 공사 API 활용을 명시하라"고 시범. **게이트(공사 API + 과제 부합)를 개요 안에 박는 것이 적격의 조건.**

### 서비스명
```
한국어 레벨 여행 가이드 '말길'
```
(예시 "여행정보 제공 플랫폼 'KTO투어'" = [유형 설명] + '[브랜드]' 구조를 따름)

### 서비스 개요
```
한국어를 배웠지만 정작 쓸 곳을 찾지 못하는 외국인을 위해, 한국관광공사
관광정보 API로 전국 관광지의 '한국어 난이도'를 산출해 자신의 실력으로
여행할 수 있는 범위를 지도로 안내하는 서비스입니다. 한국어가 늘수록 여행
지도가 수도권에서 지방으로 넓어져, 일회성 관광을 반복 방문으로 바꾸고
인구감소지역의 생활인구 유입으로 잇습니다.
```

### 이 개요에 박은 것

| 구절 | 역할 | 게이트/배점 |
|---|---|---|
| "배웠지만 정작 쓸 곳을 찾지 못하는" | 심사위원이 처음 듣는 문제. 멈칫하게 함 | 첫인상 |
| **"한국관광공사 관광정보 API로"** | **공사 OpenAPI 활용 명시** | ⛔ 게이트 ① |
| "전국 관광지의 '한국어 난이도'를 산출" | 독창성 훅 | 기획력 |
| **"일회성 관광을 반복 방문으로 / 인구감소지역의 생활인구 유입"** | **과제 4 원문을 그대로 받음** | ⛔ 게이트 ② |

### ⚠️ 접수 전 반드시 확인

1. **개요의 "한국어 난이도 산출"은 9-0(경로 B)에 의존.** 9-0 미해결로 접수는 가능하나(개발 완료는 10월), **9-0 실패로 과제를 전환하면 이 개요도 폐기.** → 접수 직전 `verify_gap2.py` 실행 권장.
2. **"관광정보 API"로 표기** — 국문/영문 구체화는 뺌. 방법론이 아직 미확정이라 개요에 못 박지 않음. 게이트는 "관광정보 API" 수준으로도 충족.
3. **중복 출품 금지 재확인** — ① 웹·앱 개발 부문 및 ②-1 프롬프톤 제출작과 동일 결과물 아님. (memory §6)

## 2. 문제 정의 → **기획력 30점**

### 2-1. 과제가 말하는 문제

> *"단순 흥미 위주 일회성 관광의 한계 및 인구 감소 지역의 지속 가능한 생활인구 유입 대책 부족"*

### 2-2. 우리가 보는 진짜 원인

일회성 관광의 원인은 **"다시 올 이유가 없다"**입니다. 그리고 정부는 이 문제를 **돈으로** 풀고 있습니다 — 반값여행(경비 50% 환급, 65억), 연박 숙박할인권, 섬 숙박할인권. **보조금이 끊기면 유입도 끊깁니다.**

말길은 **돈이 아닌 이유**를 제안합니다.

| 근거 | 수치 | 출처 |
|---|---|---|
| 한류 팬의 월평균 소비시간 **1위가 한국어** | **23.8시간** (드라마 18.3, 예능 17.7) | 2026 해외한류실태조사 (30개국 27,400명) |
| 한국어 월평균 지출 | 29.3 USD (3위) | 동일 |
| "한국어 학습자·교육기관을 쉽게 찾을 수 있다" | **33.5%만 동의** | 2025 해외한류실태조사 |
| TOPIK 응시자 (역대 최다) | **약 55만 명** / 해외 28.2만 (2020년 대비 4배) | 2025 |
| 방한객 재방문율 | **54.7%** | 2024 외래관광객조사 |
| 방한객 개별여행(FIT) 비중 | **79.3%** | 2024 |
| 세종학당 수강생 vs 방한 경로 | **23.9만 명 vs 연 222명 (0.09%)** | 2025 / 우수학습자 초청 연수 |

### 2-3. 한 문장

> **한국어는 하루에 늘지 않습니다. 그래서 다시 옵니다.**
>
> 일회성 관광의 반대말은 "체류"만이 아니라 **"반복"**입니다. 한국어 실력이 여행 범위를 결정하면, 실력이 느는 만큼 갈 곳이 넓어지고 — **다시 올 이유가 구조적으로 생깁니다.** 보조금이 필요 없습니다.

### 2-4. 왜 아무도 안 했나 (심사위원 예상 질문)

| 주체 | 왜 안 하나 |
|---|---|
| 세종학당 (273개소·23.9만 명) | 교육기관. 관광은 소관 아님 |
| 한국관광공사 | 관광기관. 학습자를 세그먼트로 본 적 없음 |
| **문체부** | **2026 업무계획에서 세종학당은 「K-컬처 해외기관」, 3천만 목표는 「K-관광」에 각각 배치. 잇는 서술 없음.** 그러면서 같은 문서가 *"K-컬처의 인기를 관광과 결합하는 전략 필요"*라고 자인 |
| 학습 앱 (트이다·디코) | 여행으로 수익 없음 |
| 여행 앱 (크리에이트립 14개어·MAU 170만) | 타깃이 중·대만·일·미. 학습자를 세그먼트로 안 봄 |
| 어학연수 (EF 등) | **전부 유럽어권. 한국어 상품 0건** |

## 4. 솔루션 → **구현성 30점**

### 4-1. 핵심 엔진 — 한국어 필요도 지도

**지역마다 "한국어가 얼마나 필요한가"를 점수화하고, 그 위에 갈 수 있는 장소를 얹습니다.**

```
① 지역 단위 — 한국어 필요도 (시군구)
   외국인 방문 비율    ← 15101972(공사, 경로 A) 또는 15000366 csForCnt/csNatCnt
   + 안내소 외국어 가능 ← 15013112 영어/일어/중국어 안내가능여부 Y/N
   = 시군구별 한국어 필요도 1~6급

② 장소 단위 — 갈 수 있는 곳
   TourAPI 국문 50,670곳 ← KorService2 areaBasedList2
   + overview 어휘 난이도 ← 국립국어원 학습용 어휘등급표 매칭
   + 예약 필요 여부      ← detailIntro2 예약안내

③ 결합
   "당신은 지금 한국의 N%를 여행할 수 있습니다"
   급수 ↑ → 지도 확장 → 다시 올 이유
```

> ⚠️ ①의 데이터 출처는 **§5-0 게이트 검증 결과에 따라 확정**됩니다. 경로 B(공사 국문∖영문 좌표 매칭) 성공 시 ①이 전부 공사 데이터로 대체됩니다.

### 4-2. 재방문 사다리

```
1차 방문 · 3급  →  서울·부산       (외국인 비율 높음 = 영어로 됨)
2차 방문 · 4급  →  지방 소도시
3차 방문 · 5급  →  인구감소지역     (+ 반값여행 50% 환급)
```

### 4-3. 왜 지방인가 — 말길의 핵심 주장

| | 서울·부산 | 지방·인구감소지역 |
|---|---|---|
| 외국인 방문 비율 | 높음 | 낮음 |
| 안내소 외국어 | 가능 | **불가** (제천 안내소 전체 N/N/N 실측 확인) |
| 학습자에게는 | **연습이 안 됨** | **가장 빨리 느는 곳** |

> **"한국어를 배우러 왔는데 서울에 있으면 영어만 쓰게 됩니다."**
>
> 지방이 **불편해서 안 가는 곳**이 아니라 **학습 효율이 가장 높은 곳**이 됩니다. 정책 목표(지방 분산)와 사용자 동기(실력 향상)가 같은 방향을 봅니다. 그리고 **인구감소지역 = 한국어 필요도 최상 = 반값여행 대상** — 가장 많이 배우는 곳이 가장 쌉니다.

### 4-4. 잠금 해제

```
[잠김] 정선 5일장 · 5급
  → 이 문장 3개면 열립니다
     "이거 얼마예요?" "좀 깎아 주세요" "이거 어떻게 먹어요?"
```
문장은 지어내지 않습니다. **해당 장소 `overview`에서 실제 어휘를 추출**합니다.

1. **`decision-rules.md` §4-1 게이트**: *"공사 OpenAPI 미활용 **또는 구색 맞추기 수준**"* → 지금이 그 경계선.
2. **심사 배점**: 「데이터 활용 **적절성** 20점」은 공사 API를 **얼마나 적절히 썼는가**를 봅니다.

### 해결 경로 — 핵심 엔진을 공사 데이터로 되찾는 두 길

| | 경로 A | 경로 B ★ |
|---|---|---|
| **방법** | 15101972(공사)의 **SKT 외국인 데이터**로 15000366(연구원)을 대체 | **15101578 ∖ 15101753 좌표 매칭** — **둘 다 공사** |
| **근거** | data.go.kr 공식 설명에 **"KT(내국인)+SKT(외국인)"** 명시 (원문 확인) | 좌표(mapx/mapy)로 id 분리를 우회 |

| **리스크** | 응답 필드 **미확인**. 운영계정 **심의승인**(일정 리스크) | 좌표 매칭 실패 시 붕괴 |

> **경로 B가 우월합니다.** 외부 데이터 없이 공사 API 두 개만으로 지표가 완성되고, *"공사 데이터를 깊이 판 사람만 할 수 있는 말"*이 되어 **데이터 활용 20점의 증거 자체**가 됩니다.
> 즉 **`verify_gap2.py`의 좌표 매칭이 성공하면 게이트 위험까지 같이 해소됩니다.**

**둘 다 실패하면**: **과제 2(오버투어리즘 분산)로 전환** 검토. 과제 2는 15128555·15128560·15101972가 **전부 공사 API**입니다.

## 7. ⚠️ 이 기획의 가장 약한 고리 (숨기지 않음)

1. **"서울에선 다 영어로 답이 온다"는 가정입니다.** 그럴듯하지만 데이터가 없습니다. 이게 틀리면 문제 정의가 통째로 무너집니다.
2. **역인과 위험** — "외국인이 안 감 → 외국어 인프라 없음"이 아니라 **"관광자원이 없어서 안 감"**일 수 있습니다. 인프라는 원인이 아니라 무관 변수일 수 있습니다.
3. **15000366은 유료관광지점 보고통계입니다.** 인구감소지역은 유료관광지점이 희소하고, 지자체가 입력을 안 하면 **0으로 표시**됩니다. **"외국인 0"이 실제 0인지 미보고인지 구분 불가**하면 지표가 무너집니다.
4. **완성도로는 ①부문을 못 이깁니다.** ①은 5월~9월 개발(2.5배) + 컨설팅. 대상은 **적정성(30)+실용성(25)**에서 따야 합니다.
