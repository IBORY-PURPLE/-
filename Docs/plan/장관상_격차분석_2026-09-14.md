## 2. 전략 층 — 코드 밖에서 고칠 것

### S1. ★ 대상 무기를 교체한다 — 옛 무기는 폐기됐다

7월 대상 검증(`daesang-check.md`)의 결론은 *"공사가 자기 약점이라 생각하는 것(다국어 데이터가 국문의 1/3)을 우리는 지표로 쓴다 — 심사위원은 이 각도를 처음 본다"*였습니다. **그 무기는 2026-09-10 P-M04로 폐기됐습니다**(외국인은 영어권만이 아님).

**새 무기 — "누가 실제로 오는가"를 공사 데이터로 전수 판정했다**

> **"공사 데이터랩 방문자 12개월 291,345행으로 전국 기초지자체 227곳을 전수 판정했습니다. 대전 중구는 외국인이 방문자 1,000명 중 4명, 구례는 4명인데 내국인은 주말에 두 배가 옵니다. 한국인에게는 확실한 관광지인데 외국인만 없는 곳 — 거기서만 한국어가 기본값입니다. 그리고 국내 유학생은 등록외국인이라, 그 동네에 한 달에 한 번 세 시간 머물면 그 지역 체류인구의 산정 요건과 같은 형태가 됩니다."**

- 공사 API 두 개(국문 관광정보 + **데이터랩 방문자수**)를 **결합해 새 값을 만든다** → 데이터 활용 20점의 증거
- 과제 4번 두 갈래를 **한 문장으로** 잇는다 → 적정성 30점(명확성 · 논리성 · 시의적절성)
- ①부문 어느 팀도 과제 4번을 이 깊이로 안 판다 → **②-2가 ①을 이길 유일한 지점 = "과제를 가장 정확히 풀었다"**

### S2. 서사를 하나로 닫는다
- **주력 = "한국어가 기본값인 인구감소지역에 등록외국인 학습자의 반복 체류를 만들고, 지자체에 증명하는 서비스"**(토론 C안). 말벗(B안)은 그 안의 가장 깊은 층 · 2단계 실증

```
Cloudflare Worker 프록시                  ← 서비스키 보관 · CORS 해결 · 호출 로그
      │ 실시간
한국관광공사 KorService2                   areaBasedList2 · detailCommon2 · detailIntro2 · ldongCode2
```
- **관광정보(장소)는 매번 실시간 호출** — 로컬 DB 적재 금지 규정 준수. 저장하는 것은 지역 급수 JSON(자체 분석 결과)뿐.
- 배포 즉시 **매일 호출 이력이 쌓이도록** 공개 URL부터 올린다(리스크 D1).
