## 1. 제품 정의

### 1-1. 한 문장

**말길은 외국인이 배운 한국어를 실제로 써먹을 수 있는 곳을 찾아 주고, 그 지도의 마지막 핀에서 사람을 만나게 하는 웹 서비스다.**

### 1-2. 무엇이 아닌가 (경계)

| 아님 | 이유 |
|---|---|
| 한국어 **학습** 앱 | 가르치지 않는다. 배운 것을 **쓸 곳**을 알려준다 |
| 여행 **가능 여부** 판정기 | 레벨이 낮아도 갈 수 있다. 다만 한국어 없이는 하루가 굴러가지 않는다 |
| 체험 **예약** 플랫폼 | 동네 말벗은 지도의 핀 하나다. 별도 탭이 없다 |
| 번역·통역 도구 | 번역기는 주문을 해결하지만 대화를 해결하지 못한다 |

### 1-3. 성공 정의

| 층위 | 지표 |
|---|---|
| **1차 (공모전)** | 1차 심사 통과 → 상위 3팀 진입. 골든 패스 에러 0 완주 |
| **2차 (제품)** | 심사위원이 진단을 끝까지 하고 최소 3개 시군구를 열어본다 |
| **3차 (사업)** | 9월 중 실제 세션 1회 개설·실행 |

## 2. 사용자

### 2-1. 페르소나

**P1 — 1차 타깃: 국내 체류 유학생 (가장 중요)**
> 응웬, 24세, 베트남, 서울 소재 대학 어학연수 2년차, TOPIK 4급.
> 한국에 2년 있었는데 아직도 친구들끼리 베트남어로 말한다. 학교 근처 프랜차이즈에만 간다. 한국어로 아르바이트 면접을 봤다가 손님 말을 못 알아들어 그만뒀다. **"제 한국어가 어디까지 통하는지 모르겠어요."**
> - 이동 자유도: 높음 (교통카드·국내 계좌 보유)
> - 결제 여력: 낮음 → **무료 세션이 진입 조건**
> - ★ 「인구감소지역 지원 특별법」 제2조제2호 다목상 **생활인구에 법적으로 해당**

**P2 — 2차 타깃: 방한 FIT 재방문객**
> 사토, 31세, 일본, 3번째 방한, 독학 TOPIK 3급 수준.
> 명동·홍대는 다 봤다. **"이번엔 일본어 간판 없는 데 가고 싶다."** 체류 5일.

**P3 — 공급자: 시니어 호스트**
> 시니어 로컬 크리에이터, 60대, 한 동네에서 40년 거주, 영어 소통 가능.
> 자기 동네 골목과 뒷산을 수십 년 걸었다. 요리로 여러 명을 이끄는 건 부담이라 **걸으며 대화하는 형태**로 코스를 재설계했다.
> - **앱을 쓰지 않는다.** 카카오톡만 쓴다 → 시니어용 화면은 5주 범위 밖 (운영자 대행)

**P4 — 실제 첫 사용자: 심사위원**
> 데스크톱 브라우저. 5분. 로그인하기 싫다. 한국인.
> → **로그인 없음 · `?demo=1` 프리셋 · 첫 화면 3초 이내 · 한국어 UI 토글**

### 2-2. 진입 시나리오

```
P1/P2 : 링크 → 진단 8문항(2분) → 레벨 → 내 레벨의 지도 → 장소 → (Lv3+) 동네 말벗
P4    : 링크 → "심사위원용 둘러보기" → Lv3 프리셋으로 즉시 지도 진입
```

## 3. 기능 요구사항

> **해시태그 5개 = 기능 8개.** 이 밖은 만들지 않는다(§6).
> 우선순위: **P0** = 없으면 제출 불가 · **P1** = 있어야 점수 · **P2** = 시간 남으면

### F1 · 한국어 레벨 진단 `#한국어레벨` `P0`

**목적** — 서비스의 유일한 진입점. 여기서 이탈하면 나머지 화면을 못 본다.

| 항목 | 사양 |
|---|---|
| 문항 수 | **고정 8문항** (적응형 아님) |
| 유형 | **읽기 전용.** 듣기·음성 합성 없음 |
| 난이도 배분 | Lv1×1, Lv2×2, Lv3×2, Lv4×2, Lv5×1 |
| 문항 언어 | **지문 = 한국어 원문 / 질문·선택지 = 영어** |
| 소요 | 2분 이내 |
| 채점 | 정답 문항의 최고 난이도 기준. 연속 2문항 오답 시 그 아래로 확정 |
| 출처 통제 | 문항 어휘·문법은 국립국어원 「2017 국제통용 한국어 표준교육과정」 어휘 10,635개·문법 336개 등급표로 통제 |
| 지문 성격 | **여행 상황 기반.** 교실 문법 문제 금지 |

**대안 트랙 (P0)** — TOPIK 보유자는 급수 입력 시 즉시 진입. 성적증명서 업로드·검증 **없음**.

**★ 공사 API 연결 (P1)** — 8문항 중 **상위 2문항(Lv4·Lv5)의 지문을 공사 `overview` 실시간 인용**으로 채운다.
- 오프라인에서 품질 필터를 통과한 장소 40곳을 골라 문항을 사람이 미리 작성
- 런타임에는 `contentid`만 들고 있다가 `detailCommon2`로 **본문을 매 회차 실시간 조회**
- **본문은 저장하지 않는다** → 진단 자체가 공사 데이터 활용 실적이 된다

**수용 기준**
- [ ] 8문항 완주까지 페이지 이동 0회, 이탈 유발 요소 없음
- [ ] 결과 화면에 **레벨 수동 조정 슬라이더**가 항상 노출 (오판정 비용을 0으로)
- [ ] 같은 답을 두 번 넣으면 같은 레벨이 나온다 (결정론적)
- [ ] `overview` 실시간 조회 실패 시 사전 저장 대체 문항으로 **무중단** 전환

### F4 · 레벨별 장소 목록 `#언어장벽제로` `P0`

시군구 선택 → 그 지역 장소 목록. **`areaBasedList2` 1콜**(`numOfRows` 상한 없음 — 종로구 844건도 1콜).

**★ 레벨과 취향의 역할 분리 (P0 — 논리 결함 방지)**

> **레벨은 무엇이 열리는지(필터)를 결정하고, 취향은 열린 것 중 무엇을 먼저 보여줄지(랭킹)를 결정한다.**

이게 없으면 TOPIK 5급 사용자에게 앱이 국밥집만 보여준다. 한국어 능력과 로컬 딥 선호는 **독립 변수**다 — 6급 화자 중에도 미슐랭에 가고 싶은 사람, K-팝 성지만 돌 사람이 있다.

- 온보딩 3문항(20초): *무엇을 하러 왔나* — 음식 / 사람·이야기 / 자연 / 역사·문화 / 쇼핑 (복수 선택)
- 태그는 새로 만들지 않는다. **`lclsSystm1` 대분류 10종**(FD 음식·NA 자연·HS 역사·VE 문화·EX 체험·SH 쇼핑·LS 레저)이 목록 응답에 100% 채워져 있으므로 **추가 호출 0**
- 정렬: `score = levelFit × (1 + 0.4 × topicMatch)`

**카드 표시**

| 구분 | 히어로 | 근거 |
|---|---|---|
| 일반 장소 | `firstimage` (**`object-fit: contain` 강제**) | 공사 이미지 70.3%가 변경금지(공공누리 제3유형) |
| **로컬 장소** | **`firstmenu`/`treatmenu` 메뉴 텍스트** | *"평양물냉면 / 함흥비빔냉면 / 모둠 버섯구이"* — 사진 없음이 결함에서 포맷으로 |

**수용 기준**
- [ ] 잠긴 장소에 **"갈 수 없음"이라고 쓰지 않는다** → "통역 없이는 어려움 — 지금도 갈 수 있지만 영어가 안 통합니다"
- [ ] 취향 미선택 사용자도 정상 동작 (topicMatch=0)
- [ ] 이미지 컴포넌트는 **1개만** 존재하고 그 안에서 `cpyrhtDivCd`를 읽어 Type1이 아니면 letterbox 강제

### F5 · 장소 상세 — 실시간 PLL 산출 `#진짜로컬` `P0`

**목적** — 데이터 활용 20점의 실물. *"방금 공사 API에서 받아 계산했습니다."*

- 진입 시 `detailCommon2` 1콜 + (음식점이면) `detailIntro2` 1콜
- **PLL을 그 자리에서 계산**해 근거와 함께 표시:
  ```
  Lv4  ·  이 장소는 한국어가 필요합니다
    · 공사 영문 관광정보 미등재
    · 반경 1km 영문 등재 2곳 (전국 중앙값 11곳)
    · 예약 안내 한국어 전용 · 신용카드 정보 없음
    산출: 2026-09-14 14:32 · 출처: ⓒ한국관광공사
  ```
- 저장하지 않는 것: title·주소·overview·이미지 URL·전화번호 (**전부 렌더 시점 호출**)

**수용 기준**
- [ ] 레벨 배지는 **상세 화면에만**. 목록·지도 카드에는 붙이지 않는다 (근거가 약한 배지 노출 방지)
- [ ] API 실패 시 에러 화면이 아니라 "다시 시도" + 캐시 폴백
- [ ] 응답이 HTTP 200 + 평면 JSON 에러여도 크래시하지 않는다

### F6 · 잠금해제 표현카드 `#진짜로컬` `P1`

잠긴 장소에서 *"이 문장 3개면 열립니다"*.

- 표현은 **해당 장소의 실제 메뉴 텍스트에서 추출**. 지어내지 않는다
- 각 카드: 한국어 원문 / 로마자 / 영어 뜻 / 언제 쓰는지
- 사용자가 "써봤어요"를 누르면 **localStorage에만** 기록 (서버 전송 없음)

**수용 기준**
- [ ] 표현이 그 장소의 `firstmenu`/`treatmenu`에서 나왔음을 화면에서 확인 가능

### F7 · 동네 말벗 `#로컬시니어` `P0`

> **공급자 = 시니어 로컬 크리에이터** (만 55세 이상 · 무자격 · 거주 10년 이상 자기신고). 시드는 전원 60대 이상으로 구성해 화면 인상을 방어한다.

> **⛔ 별도 탭 금지.** Lv3 이상 사용자가 로컬존을 열었을 때 **지도의 핀 하나**로 뜨고, 탭하면 장소 상세와 같은 레이아웃 안에 섹션으로 붙는다.

| 항목 | 사양 |
|---|---|
| 코드 범위 | **핀 노출 + 레벨 게이트 + 관심 등록 폼.** 그게 전부 |
| 세션 종류 | **2종** — S1 기사식당 밥상(Lv4) / S2 시장 단골 골목(Lv3) |
| **공급 3층** | **L1** 시드 말벗 6명(서울2+비수도권4, 인구감소지역 2+) · **L2** `recruiting` 핀(말벗 없는 지역에 정직하게) · **L3** **문화관광해설사 통합예약 `kctg.or.kr` 딥링크 — 한국관광공사 직영. P0, 말벗 카드보다 먼저 구현** |
| 정원 | **1~5명 가변, 최소 개설 1명.** 화면 표기 *"최대 5명 — 이야기가 흐르는 크기"* |
| 레벨 밴딩 | **사전 슬롯 속성.** 운영자가 'Lv3~4 슬롯'을 미리 깔고 사용자는 자기 밴드만 본다 |
| 게이트 | 미달 시 신청 버튼이 **실제로 막힌다**. 잠금이 처음으로 은유가 아니게 되는 지점 |
| **가격** | **표기하지 않는다.** "무료 파일럿 세션"으로만 게시 |
| 수집 정보 | **이메일 + 표시이름.** 그 외 없음 |
| 집합 장소 | 공사에 등재된 **앵커**(전통시장·역·공원)의 `contentid`만. 실제 목적지는 *"집합 후 도보 5분"* |

**⛔ 금지 사항 (전부 게이트 위험)**

| 금지 | 이유 |
|---|---|
| 참가비·가격 표기, 좌석 확정, 확정 메일 자동 발송 | 전자상거래법상 규제 대상은 결제가 아니라 **청약의 접수**. 사업자등록이 없으면 통신판매업 신고 불가 |
| 알레르기·식이제한 입력 | **민감정보**(개인정보보호법 §23). 확정 후 이메일로 오프라인 수집 |
| 실제 목적지를 가장 가까운 `contentid`에 **스냅** | 세션 카드에 **다른 가게 상호·사진·전화번호**가 뜬다. 허위 표시 + 무단 상호 노출 |
| 세션 XP·미션 체크·종료 코드·리포트·운영자 대시보드 | 5주 범위 밖. 위치 이력 전송 위험 |
| 특정 사업 브랜드명·로고 사용 | 텍스트 사실관계만 |

### UI 언어 원칙 (필수)

> **UI는 절대 학습 대상이 아니다. 학습 대상은 콘텐츠뿐이다.**

| 층 | 언어 |
|---|---|
| UI (버튼·네비·설명·오류·진단의 질문문과 선택지) | 사용자 모국어 (EN 기본) |
| 콘텐츠 (진단 지문, 장소명, overview, 메뉴, 시니어의 발화) | **한국어 원문 고정** |

## 5. 골든 패스 — 이것이 통과 기준

```
① 랜딩 (3초)
② 진단 8문항 (2분)
③ 레벨 카드 — "지금 열린 지역 169/264곳 · 이번 급수에 68곳"
④ 시군구 드롭다운 선택
⑤ choropleth — 내 레벨에서 열린 지역
⑥ 장소 목록 (레벨 필터 + 취향 정렬)
⑦ 장소 상세 — 실시간 PLL 산출 근거
⑧ 동네 말벗 핀 → 세션 카드 → 관심 등록
```

**9/15에 이 8단계를 로그인 없이 3분 안에 에러 0으로 완주**하는 것을 실기로 확인하고, 그 커밋을 태그로 고정한다. 이후 변경은 그 태그에서 브랜치를 따고 머지 전에 다시 완주해야 한다.
