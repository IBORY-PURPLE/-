## 0. 한 장 요약

**하려는 것을 데이터 한 줄로 옮기면 이렇습니다.**

```
인구감소지역 89곳 중에서
  ① 국문 관광정보는 두껍게 쌓였는데          ← 이미 확보 (TourAPI 국문)
  ② 영문으로는 거의 안 열렸고                 ← 이미 확보 (TourAPI 영문)
  ③ 실제로 외국인이 거의 안 오면서            ← ★신규 (관광데이터랩 방문자수)
  ④ 갈 만한 자원은 있는 곳                    ← ★신규 (관광데이터랩 수요지수)
  ⑤ 문화적 · 관광지로서 가치가 공인된 곳       ← ★신규 (오디오가이드 · 중심관광지 · 둘레길)
을 골라, 그 안에서 TOPIK 급수로 열리는 핀만 이어 여행 맵을 그린다.
그 맵을 반복해서 걸으면 ⑤ 체류인구로 잡힌다.  ← ★신규 (생활인구 통계 · 사후 측정)
```

**지금 없는 것은 ③④⑤ 세 개**입니다. 이 문서는 그 셋을 어디서 어떻게 가져오는지에 대한 계획입니다.

> **이 계획의 성립 조건 한 줄** — ①②는 "한국어로만 열린 문이 있다"를 증명하고, ③④는 "그 문 뒤가 갈 만한 곳이다"를 증명합니다. **둘 중 하나만으로는 서비스가 안 됩니다.** ①②만 있으면 "아무도 안 가는 빈 동네 목록"이고, ③④만 있으면 "그냥 여행 추천 앱"입니다.

## 3. Layer A — 어디가 인구감소지역인가 ✅

### 3-1. 원천

| 항목 | 내용 |
|---|---|
| 근거 | **행정안전부 「인구감소지역 지정」 고시** |

| 형태 | **OpenAPI 없음.** 고시 원문의 시 · 군 · 구 명단 |

### 3-2. 왜 API로 안 받고 코드표를 동봉하는가

**인구감소지역은 「고시로 지정되는 명단」이지 「계산으로 나오는 값」이 아닙니다.** 지정이 바뀌기 전까지 89곳은 상수이므로, 매번 API를 때리는 것보다 **명단을 리포지토리에 고정**하는 편이 정확하고 빠릅니다.

이미 구현되어 있습니다.

```
data/build89b.py          고시 명단(시도 · 시군구 이름) → ldongCode2 5자리로 해석 → regions.json
data/join.py              regions.json + TourAPI 덤프 → 89곳 집계
data/malgil_89_join.csv   최종 산출물 (90행 = 헤더 + 89곳)
```

**`malgil_89_join.csv` 컬럼**

```
행정표준코드5 · 시도 · 시군구 · 주민등록인구_2026-08 · 65세이상비율%
· 50-74세 · 국문관광정보 · 영문관광정보 · 영문커버율%
· 국문(쇼핑제외) · 영문(쇼핑제외) · 커버율_쇼핑제외% · 시장명칭건수
```

### 3-3. ⚠️ 유지보수 항목

| 항목 | 조치 |
|---|---|
| 고시가 개정되면 89곳이 바뀐다 | `build89b.py`의 `DECL` 딕셔너리만 교체. **고시 개정일을 파일 상단에 주석으로 박는다** |
| 행정구역 통합 · 개편 | 현재 코드표에 `전남광주통합특별시`가 등장한다. **개편 반영 시점과 고시 시점이 어긋나면 코드 해석이 깨진다** — 제출 전 `unmatched` 로그 0건 확인 필수 |

### 5-1. C-1 · 지역별 방문자수 — 「지금 외국인이 얼마나 안 오는가」

**이 API가 이 계획의 핵심입니다.** Layer B는 *"영문 정보가 없다"*까지만 말할 수 있고, *"그래서 실제로 외국인이 안 온다"*는 말할 수 없었습니다. C-1이 그 빈칸을 채웁니다.

| 항목 | 확인된 사실 |
|---|---|
| 제공기관 | 한국관광공사 AI인프라센터 |
| 원천 | **KT(내국인) · SK텔레콤(외국인)** 이동통신 데이터 |
| 「방문자」 정의 | *"거주 · 통근 · 통학 등의 일상생활권을 벗어나 관광 등의 목적으로 한 장소에 일정시간 머문 사람"* |
| 단위 | **광역 및 기초지자체별** — 시군구 조회 가능 |
| 시계열 | 데이터랩 기준 **2020년 1월부터**, 월간 조회 시 **최대 18개월** |

**말길이 뽑아 쓰는 값**

```
외국인방문자(s, 기간)   → 89곳 각각의 외국인 방문자 추세
내국인방문자(s, 기간)   → 대조군

★ 핵심 파생값
  언어장벽후보(s) = 내국인 방문자는 평균 이상인데
                    외국인 방문자는 하위인 시군구
```

> **왜 이 대조가 중요한가.** *"외국인이 안 온다"*만 보면 **원인이 「볼 게 없어서」인지 「말이 안 통해서」인지 구분되지 않습니다.** 내국인은 오는데 외국인만 안 오는 곳이라야 **자원 부족이 아니라 접근 장벽**이라는 해석이 성립합니다. 이 대조 없이 C-1을 쓰면 기획서 `[F-07]`(「인구감소지역은 영문 커버가 얕다」 가설의 반증)과 같은 실수를 반복합니다.

**호출 예산 계산**

```
89곳 × 월별 12개월 = 1,068 호출  →  개발계정 1,000회/일 초과
대응: ① 2일에 나눠 배치, 또는
      ② 기간 파라미터가 범위 조회를 지원하면 89회로 축소
      → 명세 확인 후 확정 (§12 U-2)
```

#### (2) C-7 · 관광지 오디오 가이드 — **말길에 가장 잘 맞는 데이터**

| 항목 | 확인된 사실 |
|---|---|
| 원문 | *"한국관광공사에서 제공하는 디지털 오디오 관광 해설 서비스인 **오디(Odii)**에 있는 콘텐츠의 **음성 · 대본 · 사진** 정보"* |
| **지원 언어** | **한국어 · 영어 · 중국어 · 일본어** |

> ### ★ 이 API가 말길에서 **두 가지 일을 동시에** 합니다
>
> **① 가치 신호로**: 오디오 가이드가 **있다는 것 자체**가 *"국가가 해설 콘텐츠를 제작할 만큼 문화적 가치를 인정한 곳"*이라는 뜻입니다. **인구감소지역 안에 오디오 가이드 보유 관광지가 몇 곳인지**가 그 지역의 문화 가치를 재는 가장 단단한 지표입니다.
>
> **② 학습 콘텐츠로**: 제공 필드에 **「대본(script)」**이 있습니다. **한국어 대본이 그대로 학습 자료**입니다. 기획서 §5-4가 *"메뉴판 한국어 여부는 변별력 0 → **학습 콘텐츠로 전환**"*이라고 폐기 후 재활용한 그 자리를, **이 대본이 정식으로 채웁니다.**
>
> **③ 그리고 언어 커버 신호로**: 같은 관광지에 **한국어 대본만 있는가, 영 · 중 · 일까지 있는가**가 곧 PLL의 입력입니다. Layer B(국문 vs 영문 등재)보다 **훨씬 직접적인 「이 장소가 한국어로만 열려 있다」의 증거**입니다.

**⚠️ 반드시 확인해야 할 것** — 언어별 제공 여부가 **관광지 단위로 구분되는지**(전체가 4개 국어인지, 일부만인지). §12 U-7.

## 7. 이 데이터로 무엇을 계산하는가 — 시드 지역 선정 스코어

### 7-1. 목적

**"89곳 중 어디를 Lv4~5 여행 맵의 시드로 쓸 것인가"**를 정하는 **내부 배치 지표**입니다.

> ⛔ **화면에 나오지 않습니다.** 사용자에게는 *"○○이 열렸습니다"*만 보입니다. 점수 · 백분율 노출은 기획서 **P-T01 · P-T02** 위반입니다.

### 7-2. 산식 (초안 — 캘리브레이션 대상)

```
후보(s) ∈ 인구감소지역 89곳 ∪ 관심지역 18곳

두께(s) = norm( 국문 관광정보 건수, 쇼핑 제외 )     Layer B  ✅
잠금(s) = 1 − 영문커버율(쇼핑 제외)                  Layer B  ✅
공백(s) = 1 − norm( 외국인 방문자 추세 )             Layer C-1 ★
대조(s) = norm( 내국인 방문자 추세 )                 Layer C-1 ★  ← 자원 부족과 언어 장벽을 가르는 항
가치(s) = 아래 ①②③의 결합                          Layer C-2·C-5·C-7 ★★ ← v1.1 신설
말벗(s) = norm( 50~74세 인구 )                      Layer A  ✅

  ① 해설가치 = norm( 오디오 가이드 보유 관광지 수 )        C-7
  ② 중심성   = norm( 중심 관광지 100위 진입 건수 )         C-5
  ③ 문화수요 = norm( 문화 자원 수요 지수 )                 C-2
  가치(s) = 0.40·① + 0.35·② + 0.25·③

SeedScore(s) = 0.20·두께 + 0.18·잠금 + 0.18·공백
             + 0.14·대조 + 0.20·가치 + 0.10·말벗
```

> **v1.0 대비 무엇이 달라졌나** — v1.0의 `매력(s)`(C-2 단독)을 **`가치(s)` 3항 결합**으로 교체하고 가중치를 0.10 → **0.20**으로 올렸습니다. *"국문이 두껍다"*는 **건수**일 뿐이어서, **등재만 되고 아무도 안 가는 곳**과 **국가가 해설 음성까지 만든 곳**이 같은 1건으로 잡히던 문제를 이 항이 갈라 줍니다.

### 7-3. 이 산식이 지켜야 할 규칙

| 규칙 | 이유 |
|---|---|
| **가중치는 캘리브레이션으로 확정** — 위 값은 초안 | 기획서 §9-5 · TSD §7-1과 동일 원칙 |
| **`norm`은 추세의 정규화이지 총량이 아니다** | **P-DL01** |
| **기초지자체끼리만 비교한다** | **P-DL02** |
| SeedScore와 **RLL은 다른 값**이다 | RLL = 지역 언어 난이도(사용자에게 보임) / SeedScore = 시드 선정(내부 전용) |
| 새 사용자 대면 용어를 만들지 않는다 | 기획서 §4-1 명칭 위계 보호 |

> **인구감소지역 89곳에는 국문 관광정보가 11,098곳어치 더 쌓여 있고(Layer B), 그중 「내국인은 가는데 외국인만 안 가면서, 국가가 해설 음성까지 만들어 붙인 곳」을 관광데이터랩 방문자 추세 · 중심 관광지 · 오디오 가이드로 좁혀(Layer C), TOPIK 급수로 열리는 핀만 코리아둘레길 위에서 이어 여행 맵을 그리고(§8 파이프라인), 그 반복 방문이 체류인구로 잡히는지를 생활인구 통계로 확인한다(Layer D).**
